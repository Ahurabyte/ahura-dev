# اهورا.dev — وبلاگ شخصی اهورا

وبلاگ شخصی فارسی و راست‌چین، ساخته‌شده با **Astro** + **React** + **MDX** و استایل **Tailwind CSS**.

## ✨ ویژگی‌ها

- کاملاً راست‌چین (RTL) با فونت **وزیرمتن**
- حالت روشن/تاریک با دکمه‌ی تغییر تم (جزیره‌ی React)
- پست‌ها با MDX، مرتب‌شده از جدید به قدیم
- تاریخ‌ها با اعداد فارسی (مثلاً ۲۳ مهر ۱۴۰۵)

## 🚀 اجرای محلی

```bash
npm install
npm run dev
```

بعد مرورگر رو باز کن روی `http://localhost:4321`

## 🏗️ بیلد

```bash
npm run build
```

خروجی توی پوشه‌ی `dist/` ساخته می‌شه. برای پیش‌نمایش خروجی بیلد:

```bash
npm run preview
```

## 📝 اضافه کردن پست جدید

یه فایل `.mdx` جدید توی `src/content/posts/` بساز، مثلاً `my-new-post.mdx`:

```mdx
---
title: عنوان پست
description: یه توضیح کوتاه
pubDate: 2026-10-16
---

متن پست اینجا...
```

خودکار توی صفحه‌ی اصلی و با آدرس `/posts/my-new-post/` نمایش داده می‌شه.

## 🌐 دیپلوی

سایت کاملاً استاتیکه و روی هر هاست استاتیکی کار می‌کنه. پیشنهادها:

- **Cloudflare Pages**: ریپو رو وصل کن، دستور بیلد `npm run build`، پوشه‌ی خروجی `dist`
- **Netlify**: همین تنظیمات — بیلد `npm run build`، پوشه‌ی انتشار `dist`
- **Vercel**: با فریم‌ورک Astro شناسایی خودکار می‌شه

دامنه‌ی نهایی: **ahura.dev** (بعد از دیپلوی، توی پنل هاست دامنه رو اضافه و DNS رو ست کن).

## 📁 ساختار پروژه

```
src/
  content/posts/     پست‌های وبلاگ (MDX)
  components/        کامپوننت‌های React (مثل دکمه‌ی تم)
  layouts/           قالب اصلی صفحات
  pages/             صفحه‌ی اصلی، درباره من، قالب پست
  styles/            استایل سراسری و فونت
```
