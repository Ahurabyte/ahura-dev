اگه برات سواله این سایت با چی بالا اومده، جوابش کوتاهه: **Astro**، با یه کم **React** و **MDX**.

## چرا Astro؟

چون برای یه وبلاگ، چیز بیشتری لازم نیست. Astro به‌صورت پیش‌فرض صفر جاوااسکریپت به مرورگر می‌فرسته و فقط همون چیزی رو لود می‌کنه که واقعاً لازمه. نتیجه؟ سایت سریع و سبک. ⚡

## جزیره‌های React 🏝️

جایی که تعامل لازم باشه — مثلاً دکمه‌ی تغییر تم روشن/تاریک بالای صفحه — از کامپوننت‌های React استفاده می‌کنم. به اینا می‌گن «جزیره» چون مثل جزیره‌های کوچیکی توی یه دریای استاتیک شناورن و فقط خودشون هیدراته می‌شن.

## MDX برای نوشتن

پست‌ها رو با MDX می‌نویسم؛ یعنی همون مارک‌داون راحت، به‌علاوه‌ی این امکان که هر وقت خواستم یه کامپوننت تعاملی وسط متن بذارم.

## استایل

استایل‌ها با **Tailwind CSS** نسخه‌ی ۴ نوشته شدن و سایت کاملاً راست‌چین (RTL) با فونت **وزیرمتن**ه. حالت تاریک هم داره، امتحانش کن! 🌙
